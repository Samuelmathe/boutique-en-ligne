## Lancer localement

```bash
# Serveur simple
python3 -m http.server 8080
# ou
npx --yes serve .
```

Ouvrir `http://localhost:8080`

## Fichiers

- `index.html` — structure & hero AutoLoc
- `styles.css` — thème sombre responsive
- `app.js` — catalogue, recherche, panier
